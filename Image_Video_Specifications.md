# Website Image & Video Size Specifications

This document outlines the required image dimensions and video specifications for all website assets to ensure proper layout and optimal performance.

## Image Requirements

### Hero/Slider Section (Homepage)
- Dimensions: 1920 × 960 pixels
- Aspect Ratio: 2:1
- Max File Size: 2 MB
- Formats: JPEG, PNG, JPG, GIF
- Display: Images are displayed at 600px height on the website

### Blog Cards
- Dimensions: 1200 × 800 pixels
- Aspect Ratio: 3:2
- Max File Size: 2 MB
- Formats: JPEG, PNG, JPG, GIF
- Display: Image section displays at 250px height within a 500px card

### Property Cards
- Dimensions: 1200 × 800 pixels
- Aspect Ratio: 3:2
- Max File Size: 2 MB
- Formats: JPEG, PNG, JPG, GIF
- Display: Image displays at 300px height in the card
- Additional: One main image required, multiple additional images can be uploaded

### Community Cards
- Dimensions: 1200 × 800 pixels
- Aspect Ratio: 3:2
- Max File Size: 2 MB
- Formats: JPEG, PNG, JPG, GIF, WebP
- Display: Image displays at 300px height in the card

### Off-Plan Projects
**Main Image:**
- Dimensions: 1200 × 800 pixels
- Max File Size: 2 MB

**Gallery Images:**
- Dimensions: 1200 × 800 pixels
- Max File Size: 2 MB per image
- Formats: JPEG, PNG, JPG, GIF

---

## Video Specifications

### Hero/Slider Video (Homepage)
- Formats: MP4, WebM, OGG
- Max File Size: 10 MB
- Resolution: 1920 × 1080 pixels (Full HD)
- Aspect Ratio: 16:9
- Display: Video displays at 600px height on the website

---

## General Guidelines

**Image Limitations:**
- Maximum file size: 2 MB (2048 KB)
- Supported formats: JPEG, PNG, JPG, GIF, WebP (WebP for communities only)

**Recommended Image Sizes:**
- Hero/Slider: 1920 × 960 pixels
- Blog Cards: 1200 × 800 pixels
- Property Cards: 1200 × 800 pixels
- Community Cards: 1200 × 800 pixels

**Video Limitations:**
- Maximum file size: 10 MB (10240 KB)
- Supported formats: MP4, WebM, OGG
- Recommended resolution: 1920 × 1080 pixels (Full HD)
- Aspect ratio: 16:9

---

## Best Practices

**To prevent layout issues:**
- Use the exact recommended dimensions
- Maintain the specified aspect ratios
- Do not upload images larger than the maximum file size

**For optimal performance:**
- Compress images before uploading to reduce file size
- Use JPEG format for photographs
- Use PNG format for images requiring transparency

**For best visual quality:**
- Use high-resolution source images
- Ensure images are sharp and clear
- Avoid heavily cropped or distorted images

## Upload Checklist

**Before uploading images:**
- Verify image dimensions match recommended sizes
- Confirm file size is under 2 MB
- Check that format is JPEG, PNG, JPG, or GIF
- Ensure image quality is clear and professional
- Verify aspect ratio matches specifications

**Before uploading videos:**
- Confirm resolution is 1920 × 1080 (Full HD)
- Verify file size is under 10 MB
- Check format is MP4, WebM, or OGG
- Ensure video is muted or has appropriate audio
- Verify aspect ratio is 16:9
